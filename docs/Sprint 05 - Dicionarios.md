📘 Sprint 5 — Dicionários
🎯 Objetivo

Guardar informações relacionadas entre si.

Conceito
partida = {
    "mandante": "Corinthians",
    "visitante": "Remo",
    "gols": 2
}
Estrutura
dicionario = {
    "chave": valor
}
Quando usar

Sempre que um objeto possuir vários atributos.

Exemplos:

partida
cliente
funcionário
produto
Erros comuns

Usar posição.

Dicionário usa chave.

partida["mandante"]
Anotações

Pense em uma linha de uma planilha do Excel.

Cada coluna é uma chave.
