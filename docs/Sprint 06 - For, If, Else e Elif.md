📘 Sprint 6 — For, If, Else e Elif
🎯 Objetivo

Percorrer dados e tomar decisões.

Conceito

O for visita um elemento por vez.

for partida in partidas:

Significa:

Para cada partida...

O if

if condição:

Significa:

Se...

O elif

Significa:

Senão, se...

O else

Significa:

Caso contrário...

Estrutura
for item in lista:

    if condição:

        ...

    elif outra:

        ...

    else:

        ...
Quando usar

Sempre que precisar analisar item por item.

Erros comuns

Esquecer a indentação.

Confundir

=

com

==
Anotações

O for faz perguntas repetidas.

O if responde qual caminho seguir.
