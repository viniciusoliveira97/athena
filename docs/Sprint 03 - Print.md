📘 Sprint 3 — Print
🎯 Objetivo

Mostrar informações no terminal.

🧠 Conceito principal
print("Olá")

Tudo dentro do print() será exibido.

Estrutura
print(nome)
print("Nome:", nome)
Quando usar
mostrar resultados
depurar programas
criar mensagens
Erros comuns

Esquecer a vírgula.

Errado:

print("Nome:" nome)

Correto:

print("Nome:", nome)
Anotações

O print() aceita vários argumentos separados por vírgulas.
