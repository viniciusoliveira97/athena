📘 Sprint 1 — Variáveis
🎯 Objetivo

Aprender a guardar informações na memória do computador.

🧠 Conceito principal

Uma variável é uma "caixinha" que recebe um nome.

Exemplo:

nome = "Vinicius"
idade = 30

A variável guarda um valor para ser utilizado depois.

💻 Estrutura
nome = "Athena"
idade = 25
📌 Quando usar

Sempre que uma informação será utilizada novamente.

Exemplos:

nome
idade
gols
salário
total
⚠️ Erros comuns
idade = 20
idade = 30

A segunda linha substitui a primeira.

📝 Anotações da Athena

Variáveis guardam informações.
